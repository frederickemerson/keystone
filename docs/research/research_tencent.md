## 0. TL;DR and recommended strategy

**Use both products, in different roles, and make each one leave an artifact a judge can see:**

1. **Build the app in CodeBuddy Code (CLI) + CodeBuddy IDE.** CodeBuddy Code has Plan mode (writes a Markdown plan to `.codebuddy/plans/`), Skills (`.codebuddy/skills/<name>/SKILL.md`, same shape as Anthropic Agent Skills), Sub-agents (`.codebuddy/agents/`), Agent Teams, Hooks, MCP, and a `/export` command that dumps the transcript (Markdown/JSON/ZIP). Commit `.codebuddy/` (plans, skills, agents, CODEBUDDY.md) to the GitHub repo — that is durable, inspectable proof of "built on CodeBuddy" beyond screenshots.
2. **Package the Intelligence Pill as a WorkBuddy Skill and an Expert.** WorkBuddy's official docs define a Skill as "capability", an Expert as "capability + experience", and an Expert Team as "multiple experts + a collaboration process" — which maps almost 1:1 onto MOSAIC's pills (Technical Services / Tenant Experience / Safety pills = experts; Asset Ops orchestrator = expert-team leader). Import the exported pill (SKILL.md + rules JSON) via Skills → Add skill → Upload, run a mock incident through it in WorkBuddy, and screenshot it. This gives the strongest "use of AI tools" signal because the hackathon's own product vocabulary (Expert, Expert Team, Skill) is literally the demo.
3. **Model independence ("portable")**: point the app at Tencent TokenHub's OpenAI-compatible Singapore endpoint (`https://tokenhub-intl.tencentcloudmaas.com/v1`, models `hy4-preview`, `hy3`, `deepseek-v4-pro`, `kimi-k3`, `glm-5.3` …) behind a provider switch. 1M free tokens per language model for new users. Also configure CodeBuddy Code / WorkBuddy to use the same TokenHub key (official pages exist for both) — screenshot that too.
4. **Voice onboarding**: TRTC Conversational AI is real and international (Singapore region; OpenAI-compatible LLMConfig; Tencent STT/TTS; $0.01/min + audio minutes, 10,000 free minutes/month). Official Web demo claims ~20 min to run, but it needs a Node backend holding SecretId/SecretKey and the official UIKit repo is Android/iOS only. Budget 1–1.5 days; have a browser-native fallback (Web Speech API or pre-recorded transcript) ready.
5. **ADP**: realistic only as a *bounded side-car* (e.g., publish one "Tenant Comms" knowledge agent and call it via HTTP SSE), not as the orchestrator — its human-in-the-loop is release-approval, not runtime action approval, and you would lose the version-diff/rollback story MOSAIC needs. Free plan: 10,000 credits for 1 month.
6. **Hosting**: EdgeOne Pages (free, `npm i -g edgeone`, `edgeone login` → Global, `edgeone makers deploy`) for the frontend; CodeBuddy IDE has a one-click EdgeOne Pages / Cloud Studio deploy button (screenshot it). Node backend (TRTC token + TokenHub proxy) on EdgeOne Pages Functions, CloudBase, or a $4–5/mo Lighthouse Singapore VM.

### 3.2 Agent Runtime / sandbox
- "Agent Runtime" is Tencent Cloud's agent sandbox product (KrASIA, Mar 2026: stack = ADP + "Agent Runtime" sandbox + TokenHub) https://kr-asia.com/pulses/160868 ; its open-source core is **CubeSandbox** (Apache 2.0, RustVMM/KVM MicroVMs, "Compatible with E2B SDK interface", self-deploy on x86_64 Linux with KVM, Terraform for Tencent Cloud) https://github.com/TencentCloud/CubeSandbox ; engineering write-up https://www.besthub.dev/articles/evolution-of-agent-infrastructure-engineering-insights-from-tencent-cloud-agent-runtime-0976898963ea

## 4. TRTC Conversational AI (voice onboarding call in the browser)

- Product: "AI Channel Robot joins the TRTC room"; backend calls `StartAIConversation` (`trtc.intl.tencentcloudapi.com`, regions "ap-guangzhou, ap-singapore, ap-tokyo, na-ashburn, na-siliconvalley", 50 req/s); params `SdkAppId`, `RoomId`, `AgentConfig{UserId,UserSig,TargetUserId,MaxIdleTime}`, `STTConfig{Language}`, `LLMConfig` ("must comply with the openai standard": `LLMType:"openai"`, `Model`, `APIKey`, `APIUrl`, `SystemPrompt`, `History≤50`, `Streaming`), `TTSConfig` (`TTSType:"flow"` default model `flow_01_turbo`, or `tencent`; Language `zh|en|yue`). Sources: https://www.tencentcloud.com/document/api/647/64963 ; https://trtc.io/document/65320
- Console/no-code: create app → select Conversational AI → Voice Agent > Agent Studio → configure STT (Tencent/Azure/Deepgram/Soniox), LLM (OpenAI, DeepSeek, MiniMax, Hunyuan, Coze, Dify — "any LLM model that complies with the OpenAI standard protocol"), TTS (Tencent/Cartesia/ElevenLabs/Inworld/Azure/MiniMax/Custom) → "Start Talking". Source: https://trtc.io/document/68137
- Captions/status come as custom messages (cmdID 1; type 10000 captions, 10001 robot state listening/thinking/speaking/interrupted); custom text injection and interrupt via cmdID 2. Source: https://trtc.io/document/65320 — this is exactly what MOSAIC needs to render the live transcript and "rule extracted" chips during the call.
- **Web quickstart exists:** "run through the Demo within 20 minutes"; console → RTC-Engine > Conversational AI → Quick Integration → **switch to Web** → copy SecretId/SecretKey/Config; server `npm i express tencentcloud-sdk-nodejs-trtc`; run frontend. Source: https://trtc.io/document/68999 . Web SDK is `trtc-sdk-v5` (https://npmjs.com/package/trtc-sdk-v5 ; https://github.com/Tencent-RTC/TRTC_Web).
- **Caveat:** the official UIKit repo `Tencent-RTC/AIConversationKit` contains only `Android/` and `iOS/` (GitHub tree, checked 2026-10-11) — no Web UIKit. The web demo source is downloaded from the console, not a public repo I could verify.
- Agent-assisted path: Tencent's `trtc-agent-skills` (`npx -y @tencent-rtc/trtc-agent-skills@latest add`, installs into `~/.codebuddy` etc.) includes `trtc-ai-service` whose "Quick Start" path generates a browser demo (`index.html/app.js/styles.css` + admin board) and says results "within 2-3 minutes" after 3 keys — built to be driven from CodeBuddy. Source: https://github.com/Tencent-RTC/agent-skills (skills/trtc-ai-service/SKILL.md). Running this inside CodeBuddy is itself a great proof screenshot.
- Pricing: Conversational AI service "0.01 USD/Minute" daily pay-as-you-go + audio call minutes (~$0.99/1,000 min); Tencent STT ~$0.02/min; TTS procured separately; **RTC Engine Free Trial 10,000 free minutes/month** which "can be used to offset Audio Call duration, Conversational AI Service duration and the Speech AI service". Source: https://trtc.io/document/67833 . Quick run-through says "Contact business personnel to enable AI real-time conversation service" (older page) — newer console flow self-serves; verify on signup.
- **Effort estimate:** console + Node token/StartAIConversation backend + web room join + caption rendering: 1 day for one dev if the Web demo runs as advertised; +0.5 day to pipe captions into the rule-extraction UI. Risk items: UserSig generation, Singapore region selection, service activation gating, browser mic permissions on the live URL (needs HTTPS — EdgeOne gives it). Fallback: Web Speech API ASR + TokenHub LLM + browser TTS (no Tencent dependency) or a scripted transcript replay; keep the TRTC path as the "live" showcase in the video.
